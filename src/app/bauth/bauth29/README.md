# bauth29 — Обработка отсутствующего cookie

## Цель

Реализовать корректное поведение при отсутствии session cookie.

## Тип задачи

security / session-level

## Формулировка

Реализуйте функцию `getSessionFromCookie`.

Функция принимает:

- `cookie: string | null`
- `storage: SessionStorage`

SessionStorage имеет метод:

- `find(sessionId: string): Session | null`

Необходимо:

1. Если cookie отсутствует — вернуть null
2. Если cookie присутствует, но сессия не найдена — вернуть null
3. Если сессия найдена — вернуть её

Важно:

- Отсутствие cookie не должно выбрасывать исключение
- Отсутствие сессии не является ошибкой сервера

## Ограничения

- Нельзя выбрасывать ошибки
- Нельзя использовать глобальное состояние
- Функция должна быть чистой
- Нельзя использовать реальный браузер

## Проверяемые требования

1. При cookie === null возвращается null
2. При отсутствии session в storage возвращается null
3. При наличии session возвращается объект сессии
