# bauth07 — Передача user в tRPC context

## Цель

Интегрировать auth в DI-модель
через передачу пользователя в tRPC context.

Задача формирует понимание правильной точки интеграции auth.

---

## Тип задачи

infrastructure / router integration

---

## Задание

В файле `bauth07.ts` необходимо:

1. Создать функцию createContext.
2. Принять:
   - authService
   - request
3. Получить session через authService.
4. Вернуть объект context с полем user.

Если session отсутствует — user должен быть null.

---

## Ограничения

- Нельзя импортировать auth глобально.
- Нельзя выполнять проверку ролей.
- Нельзя выбрасывать ошибки.
- Нельзя добавлять бизнес-логику.

---

## Проверяемые требования

- authService.getSession вызывается.
- user корректно извлекается из session.
- при отсутствии session возвращается user: null.
