# bauth12 — currentUser query

## Цель

Реализовать процедуру получения текущего пользователя
через context.

Задача закрепляет использование injected user
без прямого обращения к auth.

---

## Тип задачи

router

---

## Задание

В файле `bauth12.ts` необходимо:

1. Создать функцию currentUser.
2. Принять ctx с полем user.
3. Вернуть ctx.user.

---

## Ограничения

- Нельзя импортировать authService.
- Нельзя вызывать getSession.
- Нельзя выбрасывать ошибки.
- Нельзя добавлять проверку роли.
- Нельзя добавлять бизнес-логику.

---

## Проверяемые требования

- Возвращается ctx.user.
- При user = null возвращается null.
