# bauth11 — protectedProcedure

## Цель

Реализовать централизованную защиту процедур
на уровне router.

---

## Тип задачи

router

---

## Задание

В файле `bauth11.ts` необходимо:

1. Создать функцию protectedProcedure.
2. Принять:
   - ctx (с полем user)
   - handler (функция бизнес-логики)
3. Если ctx.user отсутствует —
   выбросить ошибку UNAUTHORIZED.
4. Иначе выполнить handler и вернуть результат.

---

## Ограничения

- Нельзя проверять роль.
- Нельзя работать с access-layer.
- Нельзя импортировать auth.
- Нельзя выполнять бизнес-логику внутри protectedProcedure.

---

## Проверяемые требования

- При ctx.user = null выбрасывается UNAUTHORIZED.
- При наличии пользователя вызывается handler.
- Возвращается результат handler.
