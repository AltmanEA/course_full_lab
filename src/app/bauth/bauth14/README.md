# bauth14 — adminProcedure (RBAC)

## Цель

Реализовать RBAC на уровне router:
доступ разрешён только пользователю с ролью ADMIN.

---

## Тип задачи

router

---

## Задание

В файле `bauth14.ts` необходимо:

1. Реализовать функцию adminProcedure.
2. Принять:
   - ctx (с полем user)
   - handler
3. Если user отсутствует — выбросить UNAUTHORIZED.
4. Если роль не ADMIN — выбросить FORBIDDEN.
5. Иначе выполнить handler и вернуть результат.

---

## Ограничения

- Нельзя работать с access-layer.
- Нельзя обращаться к БД.
- Нельзя добавлять бизнес-логику.
- Нельзя использовать глобальный auth.

---

## Проверяемые требования

- Нет user → UNAUTHORIZED.
- USER → FORBIDDEN.
- ADMIN → handler выполняется.
