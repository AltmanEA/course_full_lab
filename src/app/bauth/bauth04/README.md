# bauth04 — Регистрация пользователя

## Цель

Реализовать серверную регистрацию пользователя
через Better Auth.

Задача формирует понимание регистрации
как инфраструктурной операции auth-слоя.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth04.ts` необходимо:

1. Создать функцию registerUser.
2. Принять:
   - authService
   - email
   - password
3. Вызвать соответствующий метод Better Auth.
4. Вернуть результат создания пользователя.

---

## Ограничения

- Нельзя работать напрямую с таблицей users.
- Нельзя писать SQL.
- Нельзя добавлять бизнес-логику.
- Нельзя выполнять валидацию.
- Нельзя использовать глобальный auth.

---

## Проверяемые требования

- Вызван метод регистрации Better Auth.
- Параметры переданы корректно.
- Возвращён результат вызова.
