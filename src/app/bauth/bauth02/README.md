# bauth02 — Интеграция Better Auth с PostgreSQL через Drizzle

## Цель

Подключить Better Auth к базе данных PostgreSQL
через Drizzle ORM, не нарушая архитектурных границ.

Auth должен получать доступ к БД через dependency injection.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth02.ts` необходимо:

1. Расширить фабричную функцию createAuthService.
2. Принять экземпляр Drizzle database как параметр.
3. Передать его в конфигурацию Better Auth.
4. Вернуть созданный auth-экземпляр.

---

## Ограничения

- Нельзя создавать подключение к БД внутри функции.
- Нельзя импортировать глобальный db.
- Нельзя создавать singleton.
- Нельзя добавлять бизнес-логику.
- База данных должна передаваться через параметр.

---

## Проверяемые требования

- db передаётся в betterAuth.
- возможно создать несколько экземпляров с разными db.
- отсутствует module-level состояние.
