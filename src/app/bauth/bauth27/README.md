# bauth27 — CSRF-проверка для mutation

## Цель

Реализовать проверку CSRF-токена при выполнении mutation.

## Тип задачи

security / session-level

## Формулировка

Реализуйте функцию `validateCsrf`.

Функция принимает:

- `sessionToken: string | null`
- `requestToken: string | null`

Необходимо:

- если один из токенов отсутствует — выбросить ошибку
- если токены не совпадают — выбросить ошибку
- если токены совпадают — вернуть true

## Ограничения

- Нельзя использовать глобальные переменные
- Нельзя использовать внешние библиотеки
- Функция должна быть чистой
- Нельзя возвращать false — при ошибке нужно выбрасывать исключение
- Нельзя смешивать CSRF с cookie-конфигурацией

## Проверяемые требования

1. При отсутствии любого токена выбрасывается ошибка
2. При несовпадении токенов выбрасывается ошибка
3. При совпадении возвращается true
