# bauth09 — Logout и инвалидация session

## Цель

Реализовать logout через auth-инфраструктуру
и корректно завершить жизненный цикл session.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth09.ts` необходимо:

1. Создать функцию logoutUser.
2. Принять:
   - authService
   - sessionId
3. Вызвать метод инвалидирования session.
4. Не возвращать значение.

---

## Ограничения

- Нельзя работать напрямую с таблицей sessions.
- Нельзя писать SQL.
- Нельзя удалять cookie вручную.
- Нельзя использовать глобальный auth.
- Нельзя добавлять бизнес-логику.

---

## Проверяемые требования

- Вызван метод invalidation у authService.
- sessionId передан корректно.
- Функция не возвращает значение.
