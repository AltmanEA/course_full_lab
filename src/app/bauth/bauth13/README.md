# bauth13 — Расширение user моделью роли

## Цель

Добавить поле role в модель пользователя
для подготовки к реализации RBAC.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth13.ts` необходимо:

1. Создать тип Role.
2. Расширить тип User полем role.
3. Ограничить role допустимыми значениями:
   - "USER"
   - "ADMIN"

---

## Ограничения

- Нельзя реализовывать проверку роли.
- Нельзя добавлять router-логику.
- Нельзя добавлять protectedProcedure.
- Нельзя добавлять бизнес-логику.

---

## Проверяемые требования

- Тип Role объявлен корректно.
- User содержит поле role.
- Role ограничен допустимыми значениями.
