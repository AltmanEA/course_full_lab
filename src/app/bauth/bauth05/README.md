# bauth05 — Login и создание session

## Цель

Реализовать серверную аутентификацию пользователя
и создание session через auth-слой.

Задача формирует понимание session lifecycle:
login → создание session → возврат результата.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth05.ts` необходимо:

1. Создать функцию loginUser.
2. Принять:
   - authService
   - email
   - password
3. Вызвать метод login у authService.
4. Вернуть результат (включая session).

---

## Ограничения

- Нельзя работать напрямую с таблицей sessions.
- Нельзя писать SQL.
- Нельзя устанавливать cookie.
- Нельзя добавлять бизнес-логику.
- Нельзя использовать глобальный auth.

---

## Проверяемые требования

- Вызван метод login у authService.
- Параметры переданы корректно.
- Возвращён результат вызова.
