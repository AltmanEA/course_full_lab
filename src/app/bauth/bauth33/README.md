# bauth33 — Layout-level redirect

## Цель

Реализовать редирект при отсутствии авторизации на уровне layout.

## Тип задачи

ui-level / routing

## Формулировка

Реализуйте функцию `layoutGuard`.

Функция принимает:

- `user: User | null`
- `currentPath: string`

Необходимо:

- если user отсутствует — вернуть объект:
  { redirectTo: "/login" }
- если user существует — вернуть объект:
  { allow: true }

Важно:

- Нельзя выбрасывать исключение
- Нельзя выполнять серверную проверку
- Это UI-level поведение
- Функция должна быть чистой

## Проверяемые требования

1. При отсутствии user возвращается redirectTo
2. При наличии user возвращается allow: true
3. Возвращается строго один из двух вариантов
