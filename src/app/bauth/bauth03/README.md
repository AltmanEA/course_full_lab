# bauth03 — Таблицы users и sessions

## Цель

Создать схему таблиц users и sessions
для хранения пользователей и сессий.

Задача формирует понимание структуры persistence-слоя
для инфраструктуры аутентификации.

---

## Тип задачи

infrastructure / persistence

---

## Задание

В файле `bauth03.ts` необходимо:

1. Создать таблицу users.
2. Создать таблицу sessions.
3. Определить первичные ключи.
4. Определить связь session → user.

---

## Требования к таблице users

- id — primary key
- email — string
- createdAt — timestamp

---

## Требования к таблице sessions

- id — primary key
- userId — foreign key → users.id
- expiresAt — timestamp

---

## Ограничения

- Нельзя добавлять бизнес-логику.
- Нельзя создавать функции.
- Нельзя подключать auth.
- Только декларативная схема.

---

## Проверяемые требования

- Обе таблицы экспортированы.
- session содержит внешний ключ на users.
- Поля объявлены корректно.
