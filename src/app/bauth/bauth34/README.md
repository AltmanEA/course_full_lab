# bauth34 — Role-based UI rendering

## Цель

Реализовать ограничение отображения элементов интерфейса по роли пользователя.

## Тип задачи

ui-level / RBAC

## Формулировка

Реализуйте функцию `renderForRole`.

Функция принимает:

- `user: User | null`
- `requiredRole: Role`
- `content: string`

Необходимо:

- если user отсутствует — вернуть null
- если user.role !== requiredRole — вернуть null
- если user.role === requiredRole — вернуть content

Важно:

- Нельзя выбрасывать исключение
- Нельзя реализовывать server-side проверку
- Это UI-level поведение
- Функция должна быть чистой

## Проверяемые требования

1. При отсутствии user возвращается null
2. При несовпадении ролей возвращается null
3. При совпадении ролей возвращается content
