# bauth35 — Защищённая client mutation

## Цель

Реализовать клиентскую функцию, вызывающую защищённую mutation.

## Тип задачи

client-level / integration

## Формулировка

Реализуйте функцию `executeProtectedMutation`.

Функция принимает:

- `mutation: () => Promise<string>`

Необходимо:

- вызвать mutation
- если mutation успешно выполняется — вернуть результат
- если выбрасывается ошибка с именем "UnauthorizedError" —
  вернуть строку "redirect:/login"
- другие ошибки пробрасывать дальше

Важно:

- Нельзя выполнять проверку user на клиенте
- Нельзя перехватывать все ошибки без разбора
- Функция должна быть чистой

## Проверяемые требования

1. При успешном выполнении возвращается результат mutation
2. При UnauthorizedError возвращается "redirect:/login"
3. Другие ошибки пробрасываются
