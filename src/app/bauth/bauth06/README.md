# bauth06 — Получение session на сервере

## Цель

Реализовать получение текущей session
через auth-инфраструктуру в серверном окружении.

Задача формирует понимание извлечения пользователя
из session без использования глобального состояния.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth06.ts` необходимо:

1. Создать функцию getCurrentSession.
2. Принять:
   - authService
   - request (абстракция серверного запроса)
3. Вызвать метод получения session.
4. Вернуть session или null.

---

## Ограничения

- Нельзя читать cookie напрямую.
- Нельзя использовать глобальный auth.
- Нельзя добавлять проверку ролей.
- Нельзя добавлять бизнес-логику.
- Нельзя использовать router.

---

## Проверяемые требования

- Вызван метод получения session.
- request передан корректно.
- Возвращён результат вызова.
