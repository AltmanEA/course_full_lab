# bauth25 — Sliding expiration

## Цель

Реализовать продление времени жизни сессии при активности пользователя.

## Тип задачи

security / session-level

## Формулировка

Реализуйте функцию `refreshSession`.

Функция принимает:

- `session: Session`
- `ttlMs: number`
- `clock: () => number`

Необходимо:

- вычислить новое значение `expiresAt`
- expiration должно обновляться относительно текущего времени
- функция должна возвращать новый объект Session

Sliding expiration означает:

expiresAt = now + ttlMs

## Ограничения

- Нельзя использовать Date.now
- Нельзя мутировать исходный объект session
- Функция должна быть чистой
- Нельзя реализовывать absolute expiration заново
- Нельзя добавлять дополнительные поля

## Проверяемые требования

1. expiresAt обновляется относительно текущего времени
2. Возвращается новый объект (не та же ссылка)
3. userId сохраняется
4. Поведение детерминировано
