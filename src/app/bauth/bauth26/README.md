# bauth26 — Session rotation

## Цель

Реализовать механизм ротации сессии.

## Тип задачи

security / session-level

## Формулировка

Реализуйте функцию `rotateSession`.

Функция принимает:

- `session: Session`
- `generateId: () => string`

Необходимо:

- создать новую сессию
- сгенерировать новый `id`
- сохранить `userId`
- сохранить `expiresAt`

Rotation означает:
при повторной аутентификации создаётся новая сессия
с новым идентификатором.

## Ограничения

- Нельзя мутировать исходную сессию
- Нельзя использовать глобальные генераторы id
- Функция должна быть чистой
- Нельзя менять expiresAt
- Нельзя добавлять дополнительные поля

## Проверяемые требования

1. id изменяется
2. userId сохраняется
3. expiresAt сохраняется
4. Возвращается новый объект
