# bauth01 — Инициализация Better Auth

## Цель

Создать изолированный инфраструктурный модуль аутентификации
на основе Better Auth.

Задача формирует понимание auth как отдельного слоя,
не связанного напрямую с router, UI или бизнес-логикой.

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth01.ts` необходимо:

1. Создать фабричную функцию `createAuthService`.
2. Внутри неё инициализировать Better Auth.
3. Принять конфигурационный объект в качестве параметра.
4. Вернуть созданный экземпляр auth.

---

## Ограничения

- Нельзя использовать глобальное состояние.
- Нельзя создавать auth вне функции.
- Нельзя добавлять бизнес-логику.
- Нельзя импортировать router или access-layer.
- Разрешено только инфраструктурное определение auth.

---

## Проверяемые требования

- Экземпляр auth создаётся внутри функции.
- Конфигурация передаётся параметром.
- Возможно создать несколько независимых экземпляров.
- Модуль не содержит side-effect инициализации.
