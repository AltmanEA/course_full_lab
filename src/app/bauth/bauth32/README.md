# bauth32 — UI Guard-компонент

## Цель

Реализовать UI-level защиту рендера.

## Тип задачи

ui-level / security

## Формулировка

Реализуйте функцию `uiGuard`.

Функция принимает:

- `user: User | null`
- `content: string`

Необходимо:

- если user отсутствует — вернуть null
- если user существует — вернуть content

Важно:

- Нельзя выбрасывать исключение
- Нельзя выполнять серверную проверку
- UI Guard не заменяет protectedProcedure
- Функция должна быть чистой

## Проверяемые требования

1. При отсутствии user возвращается null
2. При наличии user возвращается content
3. Нет выброса исключений
