# bauth24 — Absolute expiration

## Цель

Реализовать абсолютное время жизни сессии.

## Тип задачи

security / session-level

## Формулировка

Реализуйте функцию `createSession`.

Функция принимает:

- `userId: string`
- `ttlMs: number` — время жизни сессии в миллисекундах
- `clock: () => number` — функция, возвращающая текущее время (timestamp)

Необходимо:

- создать объект сессии
- вычислить поле `expiresAt`
- expiration должно быть абсолютным: now + ttlMs

## Ограничения

- Нельзя использовать Date.now внутри функции
- Нельзя использовать глобальные переменные
- Функция должна быть чистой
- expiration не должен зависеть от активности пользователя
- Нельзя реализовывать sliding expiration

## Проверяемые требования

1. `expiresAt` равно `clock() + ttlMs`
2. Значение рассчитывается корректно при разных значениях ttl
3. Функция не использует реальное время напрямую
4. Тип возвращаемого значения соответствует `Session`
