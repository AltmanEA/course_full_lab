# bauth31 — currentUser на клиенте

## Цель

Реализовать query получения текущего пользователя.

## Тип задачи

router-level / client-integration

## Формулировка

Реализуйте функцию `currentUserQuery`.

Функция принимает:

- `ctx: Context`

Context содержит:

{
  user: User | null
}

Необходимо:

- если user отсутствует — выбросить UNAUTHORIZED
- если user существует — вернуть его

Важно:

- Нельзя импортировать auth напрямую
- Пользователь должен браться только из ctx
- Нельзя использовать глобальные переменные

## Проверяемые требования

1. При отсутствии user выбрасывается UNAUTHORIZED
2. При наличии user возвращается объект пользователя
3. Не используются скрытые зависимости
