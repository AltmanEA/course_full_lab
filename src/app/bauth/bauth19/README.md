# bauth19 — DI-гарантии в router

## Цель

Подтвердить, что router использует dependency injection
и не импортирует auth напрямую.

---

## Тип задачи

architecture

---

## Задание

В файле `bauth19.ts` необходимо:

1. Создать функцию getProfile.
2. Принять:
   - ctx (с user)
3. Вернуть user.id.

---

## Ограничения

- Нельзя импортировать authService.
- Нельзя использовать глобальный currentUser.
- Нельзя вызывать getSession.
- Нельзя обращаться к БД.
- Нельзя создавать user внутри функции.

---

## Проверяемые требования

- Используется только ctx.user.
- При отсутствии user выбрасывается UNAUTHORIZED.
