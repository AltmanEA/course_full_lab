# bauth21 — HttpOnly cookie

## Цель

Освоить обязательную настройку HttpOnly для session cookie.

## Тип задачи

security / session-level

## Формулировка

Реализуйте функцию `createSessionCookieConfig`.

Функция должна возвращать объект конфигурации cookie
для хранения идентификатора сессии.

В данной задаче требуется реализовать только одну обязательную настройку:

- cookie должна быть `HttpOnly`

## Ограничения

- Нельзя использовать глобальные переменные
- Нельзя использовать побочные эффекты
- Функция должна быть чистой
- Нельзя добавлять дополнительные поля в объект
- Нельзя удалять существующие поля

## Проверяемые требования

1. Возвращаемый объект содержит поле `httpOnly`
2. Значение `httpOnly` равно `true`
3. Тип возвращаемого значения соответствует `SessionCookieConfig`
