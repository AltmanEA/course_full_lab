# bauth08 — Session expiration

## Цель

Реализовать проверку истечения session
на инфраструктурном уровне.

Задача формирует понимание абсолютного срока действия.

---

## Тип задачи

infrastructure / security

---

## Задание

В файле `bauth08.ts` необходимо:

1. Создать функцию validateSession.
2. Принять:
   - session
   - clock (функция, возвращающая текущую дату)
3. Если session.expiresAt меньше текущего времени —
   вернуть null.
4. Иначе вернуть session.

---

## Ограничения

- Нельзя использовать Date.now напрямую.
- Нельзя изменять session.
- Нельзя выбрасывать ошибки.
- Нельзя использовать глобальное состояние.

---

## Проверяемые требования

- Просроченная session возвращает null.
- Валидная session возвращается.
- Используется injected clock.
