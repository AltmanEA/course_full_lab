# bauth15 — ADMIN-only mutation

## Цель

Применить adminProcedure к конкретной mutation
и закрепить практическое использование RBAC.

---

## Тип задачи

router

---

## Задание

В файле `bauth15.ts` необходимо:

1. Создать функцию deleteUser.
2. Принять:
   - ctx
   - handler (бизнес-логика удаления)
3. Использовать adminProcedure для защиты.
4. Вернуть результат handler.

---

## Ограничения

- Нельзя проверять роль вручную.
- Нельзя дублировать логику RBAC.
- Нельзя обращаться к БД напрямую.
- Нельзя добавлять ownership.
- Нельзя импортировать auth.

---

## Проверяемые требования

- Нет user → UNAUTHORIZED.
- USER → FORBIDDEN.
- ADMIN → handler выполняется.
