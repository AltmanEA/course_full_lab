# bauth10 — Полный lifecycle аутентификации

## Цель

Сформировать целостную инфраструктурную модель
жизненного цикла аутентификации:

- регистрация
- login
- получение session
- logout

---

## Тип задачи

infrastructure

---

## Задание

В файле `bauth10.ts` необходимо:

1. Создать функцию runAuthLifecycle.
2. Принять:
   - authService
   - email
   - password
   - request
3. Выполнить:
   - регистрацию
   - login
   - получение session
   - logout
4. Вернуть объект с результатами выполнения шагов.

---

## Ограничения

- Нельзя работать напрямую с БД.
- Нельзя использовать глобальный auth.
- Нельзя добавлять router.
- Нельзя добавлять бизнес-логику.
- Нельзя менять порядок операций.

---

## Проверяемые требования

- Методы вызываются в правильной последовательности.
- Параметры передаются корректно.
- Возвращается агрегированный результат.
