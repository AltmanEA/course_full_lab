# drizzle18 — Join + where по связанной таблице

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с join и условием выборки
по полю связанной таблицы.

## Тип задачи
ORM / JOIN / select / where

## Задание
Реализовать функцию `selectGradesByStudentId`, которая формирует select-запрос
для получения оценок конкретного студента.

Запрос должен:
- использовать join между таблицами `grades` и `students`;
- содержать условие `where` по полю `students.id`.

Соединение выполняется по полям `grades.studentId` и `students.id`.

Функция принимает:
- объект базы данных;
- таблицу оценок;
- таблицу студентов;
- функцию сравнения;
- идентификатор студента.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используется метод `innerJoin`.
- Используется метод `where`.
- Условие `where` формируется по `students.id`.
- Функция возвращает результат select-цепочки.
