# drizzle09 — Update записи по условию

## Цель задачи
Научиться формировать update-запрос Drizzle ORM с условием обновления.

## Тип задачи
ORM / CRUD / update / where

## Задание
Реализовать функцию `updateStudentNameById`, которая формирует update-запрос
Drizzle для обновления имени студента по его идентификатору.

Функция принимает:
- объект базы данных;
- таблицу студентов;
- функцию сравнения;
- идентификатор студента;
- новое имя.

Функция должна вернуть результат выполнения update-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `update`.
- Update применяется к таблице `students`.
- Используется метод `set`.
- Используется метод `where`.
- Условие формируется по полю `id`.
- Функция возвращает результат update-цепочки.
