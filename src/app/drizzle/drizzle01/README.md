# drizzle01 — Схема таблицы с использованием Drizzle

## Цель

Описать схему таблицы базы данных с использованием **Drizzle ORM**.

## Тип задачи

Server / структурная

## Задание

Описать таблицу с именем `users`, используя Schema API Drizzle ORM.

Таблица **обязана** содержать следующие колонки:

- `id`
- `email`
- `createdAt`

Определение таблицы должно быть **декларативным** и опираться только на примитивы Drizzle, рассмотренные в лекции 1.

Использование сырого SQL запрещено.

## Ожидаемые артефакты

- Файл со схемой, в котором определена таблица `users`
- Определение таблицы должно быть экспортировано

## Ограничения

- Нельзя использовать raw SQL
- Нельзя использовать другие ORM, кроме Drizzle
- Нельзя хардкодить SQL-строки, зависящие от СУБД

## Что проверяется

- Имя таблицы
- Наличие обязательных колонок
- Использование Schema API Drizzle
- Декларативный стиль описания
