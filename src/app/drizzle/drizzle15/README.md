# drizzle15 — Агрегатный select (count)

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с использованием агрегатной функции.

## Тип задачи
ORM / CRUD / select / aggregate / count

## Задание
Реализовать функцию `countStudents`, которая формирует select-запрос
Drizzle для подсчёта количества студентов.

Функция принимает:
- объект базы данных;
- таблицу студентов;
- агрегатную функцию подсчёта.

Функция должна вернуть результат выполнения агрегатного select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено добавлять условия, сортировку или ограничения.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- В `select` передаётся агрегатное выражение `count`.
- Используется метод `from`.
- Агрегация применяется к таблице `students`.
- Функция возвращает результат select-цепочки.
