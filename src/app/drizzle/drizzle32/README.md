# drizzle32 — Обработка ошибки БД с пробросом новой ошибки

## Цель задачи
Научиться корректно обрабатывать ошибку data-access слоя
и пробрасывать новую ошибку наружу.

## Тип задачи
Next.js / Drizzle / error-handling

## Задание
Реализовать функцию `safeLoadStudents`, которая:
- принимает асинхронную функцию загрузки данных;
- вызывает её;
- при ошибке выбрасывает новый Error с сообщением "Database error";
- при успешном выполнении возвращает результат загрузки.

Функция должна быть асинхронной.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено проглатывать ошибку.
- Запрещено возвращать fallback вместо ошибки.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется `await`.
- Используется конструкция `try/catch`.
- При ошибке выбрасывается новый Error.
- При успехе возвращается исходный результат.
