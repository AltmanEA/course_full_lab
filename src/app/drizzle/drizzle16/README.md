# drizzle16 — Inner join двух таблиц

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с использованием inner join.

## Тип задачи
ORM / JOIN / select / innerJoin

## Задание
Реализовать функцию `selectGradesWithStudents`, которая формирует select-запрос
для получения оценок вместе с данными студентов.

Запрос должен использовать `innerJoin` между таблицами:
- `grades`
- `students`

Соединение выполняется по полям `grades.studentId` и `students.id`.

Функция принимает:
- объект базы данных;
- таблицу оценок;
- таблицу студентов;
- функцию сравнения полей.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используется метод `innerJoin`.
- Join выполняется по `grades.studentId = students.id`.
- Функция возвращает результат select-цепочки.
