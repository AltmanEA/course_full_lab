# drizzle33 — Server-only поведение с runtime-эффектом

## Цель задачи
Научиться моделировать server-only поведение через проверяемый runtime-эффект.

## Тип задачи
Next.js / Drizzle / server-only

## Задание
Реализовать функцию `serverOnlyAction`, которая:
- принимает объект с методом `run`;
- выполняет этот метод;
- выбрасывает ошибку, если метод отсутствует.

Функция должна быть предназначена только для серверного использования.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено проверять наличие "use server" строкой.
- Запрещено изменять тесты.

## Проверяемые требования
- Метод `run` вызывается при корректном объекте.
- При отсутствии метода `run` выбрасывается ошибка.
- Ошибка имеет детерминированное сообщение.
