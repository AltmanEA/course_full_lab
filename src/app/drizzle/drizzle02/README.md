# drizzle02 — Ограничения и значения по умолчанию

## Цель

Освоить задание ограничений и значений по умолчанию при описании таблиц с помощью Drizzle ORM.

## Тип задачи

Server / структурная

## Задание

Описать таблицу `users` с использованием Schema API Drizzle ORM так, чтобы выполнялись следующие условия:

- у таблицы есть первичный ключ;
- как минимум одно поле имеет ограничение `not null`;
- как минимум одно поле имеет значение по умолчанию.

Структура таблицы (набор полей и их типы) определяется студентом самостоятельно.

Описание должно быть выполнено декларативно, без использования raw SQL.

## Ожидаемые артефакты

- Файл со схемой таблицы `users`
- Экспортируемое определение таблицы

## Ограничения

- Запрещено использование raw SQL
- Запрещено использование других ORM
- Все ограничения должны задаваться через Schema API Drizzle

## Что проверяется

- Наличие первичного ключа
- Использование `notNull()`
- Использование `default(...)` или `defaultNow()`
- Декларативное описание схемы
