# drizzle28 — Data-access функция с параметрами

## Цель задачи
Научиться писать data-access функцию, которая инкапсулирует
логику формирования запроса и принимает параметры.

## Тип задачи
Next.js / Drizzle / data-access

## Задание
Реализовать функцию `getStudentsLimited`, которая:
- принимает объект базы данных;
- принимает параметр `limit`;
- формирует select-запрос;
- применяет ограничение количества записей.

Функция должна вернуть результат выполнения запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено импортировать db напрямую.
- Запрещено использовать реальную базу данных.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется переданный объект db.
- Используется метод `select`.
- Используется метод `limit`.
- Значение `limit` берётся из аргумента функции.
- Результат запроса возвращается без изменений.
