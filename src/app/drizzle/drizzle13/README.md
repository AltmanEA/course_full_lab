# drizzle13 — Select с limit и offset

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с ограничением количества
результатов и смещением выборки (пагинация).

## Тип задачи
ORM / CRUD / select / limit / offset

## Задание
Реализовать функцию `selectStudentsPage`, которая формирует select-запрос
Drizzle для получения страницы студентов с использованием `limit` и `offset`.

Функция принимает:
- объект базы данных;
- таблицу студентов;
- значение limit;
- значение offset.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используется метод `limit`.
- Используется метод `offset`.
- `limit` и `offset` вызываются с переданными значениями.
- Функция возвращает результат select-цепочки.
