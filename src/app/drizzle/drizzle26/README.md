# drizzle26 — Server-only доступ к базе

## Цель задачи
Зафиксировать, что доступ к базе данных осуществляется только в server-контексте.

## Тип задачи
Next.js / Drizzle / server-only

## Задание
Реализовать функцию `serverSelect`, которая выполняет select-запрос,
используя переданный объект базы данных.

Функция должна быть помечена как server-only.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено изменять тесты.

## Проверяемые требования
- Файл помечен как server-only.
- Используется переданный объект db.
- Возвращается результат вызова db API.
