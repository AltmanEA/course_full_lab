# drizzle03 — Формирование SELECT-запроса с помощью Drizzle

## Цель

Научиться формировать SELECT-запросы с использованием Query API Drizzle ORM.

## Тип задачи

Server / запросы

## Задание

В файле `schema.ts`:

1. Описать таблицу `users` с использованием Schema API Drizzle ORM.
2. Реализовать функцию `selectUsers`, которая формирует запрос выборки
   всех записей из таблицы `users` с использованием Query API Drizzle ORM.

Функция должна принимать объект базы данных (`db`) как параметр  
и **не должна выполнять запрос**, только формировать его.

## Ограничения

- Разрешено вносить изменения **только в файл `schema.ts`**.
- Запрещено использование raw SQL.
- Запрещено дублировать описание таблицы.
- Запрос должен формироваться через Query API Drizzle.

## Что проверяется

- Наличие таблицы `users`.
- Реализация функции `selectUsers`.
- Использование `db.select().from(users)`.
