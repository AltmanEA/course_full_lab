# drizzle04 — SELECT-запрос с условием WHERE в Drizzle

## Цель

Научиться формировать SELECT-запросы с условиями
с использованием Query API Drizzle ORM.

## Тип задачи

Server / запросы

## Задание

В файле `schema.ts`:

1. Описать таблицу `users` с использованием Schema API Drizzle ORM.
2. Реализовать функцию `selectUserByEmail`,
   которая формирует запрос выборки пользователя по email
   с использованием Query API Drizzle ORM.

Функция должна:

- принимать объект базы данных (`db`) как параметр;
- принимать email как параметр;
- формировать запрос с использованием условия `where`;
- не выполнять запрос, а только возвращать выражение.

## Ограничения

- Разрешено вносить изменения **только в файл `schema.ts`**.
- Запрещено использование raw SQL.
- Запрещено дублировать описание таблицы.
- Условие должно быть сформировано через Query API Drizzle.

## Что проверяется

- Наличие таблицы `users`.
- Реализация функции `selectUserByEmail`.
- Использование `where(...)`.
- Использование колонки `users.email` в условии.
