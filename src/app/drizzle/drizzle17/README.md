# drizzle17 — Left join

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с использованием left join.

## Тип задачи
ORM / JOIN / select / leftJoin

## Задание
Реализовать функцию `selectAssignmentsWithGrades`, которая формирует
select-запрос для получения списка заданий и связанных с ними оценок.

Запрос должен использовать `leftJoin` между таблицами:
- `assignments`
- `grades`

Соединение выполняется по полям `assignments.id` и `grades.assignmentId`.

Функция принимает:
- объект базы данных;
- таблицу заданий;
- таблицу оценок;
- функцию сравнения полей.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используется метод `leftJoin`.
- Join выполняется по `assignments.id = grades.assignmentId`.
- Функция возвращает результат select-цепочки.
