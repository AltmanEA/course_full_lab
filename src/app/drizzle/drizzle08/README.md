# drizzle08 — Select с условием where

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с условием выборки.

## Тип задачи
ORM / CRUD / select / where

## Задание
Реализовать функцию `selectStudentByEmail`, которая формирует select-запрос
Drizzle для получения одного студента по email.

Функция принимает:
- объект базы данных;
- таблицу студентов;
- email студента.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено добавлять сортировку или ограничения.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используется метод `where`.
- Условие выборки формируется по полю `email`.
- Функция возвращает результат select-цепочки.
