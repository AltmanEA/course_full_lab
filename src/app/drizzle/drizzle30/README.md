# drizzle30 — Server Component loader с async-логикой и fallback

## Цель задачи
Научиться писать server-side loader для Server Component
с асинхронной загрузкой данных и fallback-логикой.

## Тип задачи
Next.js / Drizzle / server-component / async

## Задание
Реализовать функцию `loadStudents`, которая:
- является асинхронной;
- вызывает переданную функцию загрузки данных;
- при отсутствии данных возвращает fallback-значение;
- иначе возвращает полученные данные.

Функция принимает:
- асинхронную функцию загрузки данных;
- fallback-значение.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено импортировать db напрямую.
- Запрещено использовать реальную базу данных.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется `await`.
- Data-loader вызывается ровно один раз.
- Реализована ветка fallback.
- Возвращается либо результат загрузки, либо fallback.
