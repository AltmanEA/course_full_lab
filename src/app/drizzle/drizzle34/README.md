# drizzle34 — Повторное использование data-access без дублирования логики

## Цель задачи
Научиться повторно использовать data-access функцию,
не дублируя её логику.

## Тип задачи
Next.js / Drizzle / reuse / architecture

## Задание
В файле объявлены две функции:

- `getStudents` — возвращает массив студентов.
- `getStudentsNames` — должна вернуть массив имён студентов.

Реализовать `getStudentsNames` так, чтобы:
- она вызывала `getStudents`;
- не дублировала логику получения студентов;
- преобразовывала результат в массив имён.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено изменять `getStudents`.
- Запрещено дублировать логику получения данных.
- Запрещено изменять тесты.

## Проверяемые требования
- `getStudents` вызывается ровно один раз.
- Возвращается массив имён.
- Логика получения данных не продублирована.
