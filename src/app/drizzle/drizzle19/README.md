# drizzle19 — Join + выборка ограниченных полей

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с join и выборкой
ограниченного набора полей из разных таблиц.

## Тип задачи
ORM / JOIN / select / projection

## Задание
Реализовать функцию `selectStudentEmailAndGrade`, которая формирует select-запрос
для получения:
- email студента;
- балла за задание.

Запрос должен:
- использовать join между таблицами `grades` и `students`;
- выбирать только поля `students.email` и `grades.score`.

Соединение выполняется по полям `grades.studentId` и `students.id`.

Функция принимает:
- объект базы данных;
- таблицу оценок;
- таблицу студентов;
- функцию сравнения.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select` с объектом полей.
- Используется метод `from`.
- Используется метод `innerJoin`.
- Выбираются поля из двух таблиц.
- Функция возвращает результат select-цепочки.
