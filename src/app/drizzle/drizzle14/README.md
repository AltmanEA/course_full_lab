# drizzle14 — Delete по составному условию

## Цель задачи
Научиться формировать delete-запрос Drizzle ORM с составным условием удаления.

## Тип задачи
ORM / CRUD / delete / where / and

## Задание
Реализовать функцию `deleteGradeByStudentAndAssignment`, которая формирует
delete-запрос Drizzle для удаления оценки студента за конкретное задание.

Функция принимает:
- объект базы данных;
- таблицу оценок;
- функцию объединения условий;
- функцию сравнения;
- идентификатор студента;
- идентификатор задания.

Функция должна вернуть результат выполнения delete-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `delete`.
- Delete применяется к таблице `grades`.
- Используется метод `where`.
- Условие включает проверку по `studentId` и `assignmentId`.
- Используется объединение условий.
- Функция возвращает результат delete-цепочки.
