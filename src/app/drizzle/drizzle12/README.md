# drizzle12 — Select с сортировкой

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с сортировкой результатов.

## Тип задачи
ORM / CRUD / select / orderBy

## Задание
Реализовать функцию `selectAssignmentsOrderedByMaxScore`, которая формирует
select-запрос Drizzle для получения списка заданий, отсортированных по полю
`maxScore` по убыванию.

Функция принимает:
- объект базы данных;
- таблицу заданий;
- функцию сортировки.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используется метод `orderBy`.
- Сортировка применяется по полю `maxScore`.
- Функция возвращает результат select-цепочки.
