# drizzle35 — Итоговый data-flow (Action → Access → Drizzle)

## Цель задачи
Зафиксировать корректную архитектуру передачи данных:
Server Action → Data-access → Drizzle API.

## Тип задачи
Next.js / Drizzle / architecture / DI

## Задание
Реализовать функцию `studentsCountFlow`, которая:

1. Принимает:
   - функцию server action;
   - функцию data-access;
   - объект db.

2. Должна:
   - вызвать server action;
   - внутри неё вызвать data-access;
   - передать db в data-access;
   - вернуть итоговый результат.

Все зависимости должны передаваться через параметры (DI-модель).

## Ограничения
- Разрешено изменять только файл `schema.ts`.
- Запрещено использовать глобальные переменные.
- Запрещено импортировать db напрямую.
- Запрещено изменять тесты.

## Проверяемые требования
- server action вызывается один раз.
- data-access вызывается один раз.
- db передаётся в data-access.
- Возвращается результат нижнего слоя.
