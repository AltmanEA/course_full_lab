# drizzle29 — Server Action с трансформацией результата

## Цель задачи
Научиться писать server action, которая вызывает data-access функцию
и выполняет дополнительную обработку результата.

## Тип задачи
Next.js / Drizzle / server-action

## Задание
Реализовать функцию `getStudentsCountAction`, которая:
- принимает data-access функцию;
- вызывает её;
- трансформирует результат;
- возвращает итоговое значение.

В рамках задачи требуется вернуть **количество элементов** в результате
data-access функции.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено импортировать db напрямую.
- Запрещено использовать реальную базу данных.
- Запрещено изменять тесты.

## Проверяемые требования
- Data-access функция вызывается ровно один раз.
- Результат data-access функции трансформируется.
- Возвращается новое значение, а не исходный результат.
