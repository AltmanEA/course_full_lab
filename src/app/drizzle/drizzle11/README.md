# drizzle11 — Select с ограничением полей

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с выборкой ограниченного набора полей.

## Тип задачи
ORM / CRUD / select / projection

## Задание
Реализовать функцию `selectStudentEmails`, которая формирует select-запрос
Drizzle для получения списка студентов, содержащего **только поля `id` и `email`**.

Функция принимает:
- объект базы данных;
- таблицу студентов.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- В `select` передаётся объект с полями `id` и `email`.
- Используется метод `from`.
- `from` вызывается с таблицей `students`.
- Функция возвращает результат select-цепочки.
