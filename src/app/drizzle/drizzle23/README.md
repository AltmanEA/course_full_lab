# drizzle23 — Сортировка по агрегатному значению

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с агрегацией, группировкой
и сортировкой по агрегатному значению.

## Тип задачи
ORM / JOIN / select / aggregate / groupBy / orderBy

## Задание
Реализовать функцию `selectAssignmentsOrderedByGradesCount`, которая формирует
select-запрос для получения заданий, отсортированных по количеству оценок.

Запрос должен:
- использовать join между таблицами `assignments` и `grades`;
- использовать агрегатную функцию `count`;
- использовать `groupBy` по `assignments.id`;
- использовать `orderBy` по агрегатному значению количества оценок (по убыванию).

Соединение выполняется по полям:
- `assignments.id = grades.assignmentId`

Функция принимает:
- объект базы данных;
- таблицу заданий;
- таблицу оценок;
- функцию сравнения;
- агрегатную функцию `count`;
- функцию сортировки по убыванию.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select` с агрегатным выражением.
- Используется метод `from`.
- Используется метод `innerJoin`.
- Используется метод `groupBy`.
- Используется метод `orderBy`.
- Сортировка применяется к агрегатному значению.
- Функция возвращает результат select-цепочки.
