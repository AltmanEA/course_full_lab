# drizzle20 — Many-to-many через промежуточную таблицу

## Цель задачи
Научиться формировать select-запрос Drizzle ORM для many-to-many связи
через промежуточную таблицу.

## Тип задачи
ORM / JOIN / select / many-to-many

## Задание
Реализовать функцию `selectAssignmentsByStudent`, которая формирует select-запрос
для получения списка заданий конкретного студента.

Запрос должен:
- использовать два join подряд:
  - `students → grades`
  - `grades → assignments`;
- выбирать данные из таблицы `assignments`;
- содержать условие `where` по `students.id`.

Соединения выполняются по полям:
- `students.id = grades.studentId`
- `grades.assignmentId = assignments.id`

Функция принимает:
- объект базы данных;
- таблицу студентов;
- таблицу оценок;
- таблицу заданий;
- функцию сравнения;
- идентификатор студента.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- Используются **два join подряд**.
- Используется метод `where`.
- Соединения выполняются по корректным полям.
- Функция возвращает результат select-цепочки.
