# drizzle10 — Delete записи по условию

## Цель задачи
Научиться формировать delete-запрос Drizzle ORM с условием удаления.

## Тип задачи
ORM / CRUD / delete / where

## Задание
Реализовать функцию `deleteAssignmentById`, которая формирует delete-запрос
Drizzle для удаления одного задания по его идентификатору.

Функция принимает:
- объект базы данных;
- таблицу заданий;
- функцию сравнения;
- идентификатор задания.

Функция должна вернуть результат выполнения delete-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `delete`.
- Delete применяется к таблице `assignments`.
- Используется метод `where`.
- Условие формируется по полю `id`.
- Функция возвращает результат delete-цепочки.
