# drizzle06 — Insert одной записи

## Цель задачи
Научиться формировать insert-запрос Drizzle ORM для добавления одной записи.

## Тип задачи
ORM / CRUD / insert

## Задание
Реализовать функцию `insertStudent`, которая формирует insert-запрос Drizzle
для добавления одной записи в таблицу `students`.

Функция принимает:
- объект базы данных;
- данные студента.

Функция должна вернуть результат выполнения insert-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `insert`.
- Insert применяется к таблице `students`.
- В `values` передаётся объект с данными студента.
- Функция возвращает результат insert-цепочки.
