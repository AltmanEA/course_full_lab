# drizzle31 — Явная обработка отсутствующих данных

## Цель задачи
Научиться явно обрабатывать отсутствие данных,
полученных из data-access слоя.

## Тип задачи
Next.js / Drizzle / data-handling

## Задание
Реализовать функцию `getStudentOrNull`, которая:
- принимает функцию загрузки одного студента;
- вызывает её;
- если результат отсутствует (`null` или `undefined`), возвращает `null`;
- иначе возвращает полученный объект.

Функция должна быть асинхронной.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется `await`.
- Функция загрузки вызывается ровно один раз.
- При отсутствии данных возвращается `null`.
- При наличии данных возвращается исходный объект.
