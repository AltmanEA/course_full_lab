# drizzle24 — Транзакция с двумя запросами

## Цель задачи
Научиться формировать транзакцию Drizzle ORM с выполнением нескольких запросов
внутри одной транзакции.

## Тип задачи
ORM / transaction / insert / update

## Задание
Реализовать функцию `createGradeWithCounterUpdate`, которая формирует транзакцию,
внутри которой выполняются два запроса:

1. Добавление новой оценки.
2. Обновление счётчика оценок у студента.

Функция принимает:
- объект базы данных;
- функцию вставки оценки;
- функцию обновления счётчика;
- данные для вставки;
- данные для обновления.

Оба запроса должны быть выполнены **внутри транзакции**.

Функция должна вернуть результат выполнения транзакции.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `transaction`.
- Оба запроса выполняются внутри callback транзакции.
- Оба запроса вызываются ровно один раз.
- Функция возвращает результат транзакции.
