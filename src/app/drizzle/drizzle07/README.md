# drizzle07 — Select всех записей

## Цель задачи
Научиться формировать select-запрос Drizzle ORM для получения всех записей таблицы.

## Тип задачи
ORM / CRUD / select

## Задание
Реализовать функцию `selectAllStudents`, которая формирует select-запрос
Drizzle для получения всех записей из таблицы `students`.

Функция принимает:
- объект базы данных;
- таблицу студентов.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено добавлять условия, сортировку или ограничения.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select`.
- Используется метод `from`.
- `from` вызывается с таблицей `students`.
- Не используются `where`, `limit`, `orderBy`.
- Функция возвращает результат select-цепочки.
