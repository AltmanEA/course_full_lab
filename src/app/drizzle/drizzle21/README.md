# drizzle21 — Агрегация по связанным данным

## Цель задачи
Научиться формировать select-запрос Drizzle ORM с join и агрегатной функцией
для подсчёта связанных записей.

## Тип задачи
ORM / JOIN / select / aggregate / count

## Задание
Реализовать функцию `countGradesByStudent`, которая формирует select-запрос
для подсчёта количества оценок конкретного студента.

Запрос должен:
- использовать join между таблицами `students` и `grades`;
- использовать агрегатную функцию `count`;
- содержать условие `where` по `students.id`.

Соединение выполняется по полям:
- `students.id = grades.studentId`

Функция принимает:
- объект базы данных;
- таблицу студентов;
- таблицу оценок;
- функцию сравнения;
- агрегатную функцию `count`;
- идентификатор студента.

Функция должна вернуть результат выполнения select-запроса.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `select` с агрегатным выражением.
- Используется метод `from`.
- Используется метод `innerJoin`.
- Используется метод `where`.
- Агрегация применяется к таблице `grades`.
- Функция возвращает результат select-цепочки.
