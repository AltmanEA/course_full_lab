# drizzle27 — Singleton-инициализация db

## Цель задачи
Научиться инициализировать объект базы данных как singleton
в серверном окружении.

## Тип задачи
Next.js / Drizzle / server / singleton

## Задание
Реализовать функцию `getDb`, которая возвращает экземпляр базы данных.
При повторных вызовах функция должна возвращать **тот же самый объект**.

Функция принимает фабрику создания базы данных.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено изменять тесты.

## Проверяемые требования
- Фабрика создания базы вызывается только один раз.
- Повторные вызовы возвращают один и тот же объект.
