# drizzle05 — INSERT-запрос с возвращаемым значением в Drizzle

## Цель

Научиться формировать INSERT-запросы с использованием
Query API Drizzle ORM.

## Тип задачи

Server / запросы

## Задание

В файле `schema.ts`:

1. Описать таблицу `users` с использованием Schema API Drizzle ORM.
2. Реализовать функцию `insertUser`,
   которая формирует запрос вставки пользователя в таблицу `users`
   с использованием Query API Drizzle ORM.

Функция должна:

- принимать объект базы данных (`db`) как параметр;
- принимать объект с данными пользователя;
- формировать INSERT-запрос;
- возвращать запрос с использованием `returning()`.

Функция **не должна выполнять запрос**, только формировать выражение.

## Ограничения

- Разрешено вносить изменения **только в файл `schema.ts`**.
- Запрещено использование raw SQL.
- Запрещено дублировать описание таблицы.
- Запрос должен формироваться через Insert API Drizzle.

## Что проверяется

- Наличие таблицы `users`.
- Реализация функции `insertUser`.
- Использование `insert()` и `values()`.
- Использование `returning()`.
