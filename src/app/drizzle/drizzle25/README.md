# drizzle25 — Rollback при ошибке в транзакции

## Цель задачи
Научиться формировать транзакцию Drizzle ORM, в которой ошибка приводит
к откату транзакции (rollback) и пробросу исключения наружу.

## Тип задачи
ORM / transaction / error-handling / rollback

## Задание
Реализовать функцию `createGradeWithRollback`, которая формирует транзакцию,
внутри которой выполняются два шага:

1. Выполняется первая операция.
2. Если вторая операция выбрасывает ошибку, транзакция должна быть прервана.

Ошибка должна:
- остановить выполнение второй операции;
- быть проброшена наружу из транзакции.

Функция принимает:
- объект базы данных;
- первую операцию;
- вторую операцию;
- данные для первой операции;
- данные для второй операции.

Функция должна вернуть результат выполнения транзакции
или выбросить ошибку.

## Ограничения
- Разрешено изменять **только файл `schema.ts`**.
- Запрещено использовать реальную базу данных.
- Запрещено использовать raw SQL.
- Запрещено перехватывать ошибку и скрывать её.
- Запрещено изменять тесты.

## Проверяемые требования
- Используется метод `transaction`.
- Обе операции выполняются внутри callback транзакции.
- При ошибке вторая операция не завершается успешно.
- Ошибка пробрасывается наружу.
