# trpc17 — Разделение router по сущности

## Цель задачи

Освоить разделение процедур по доменной модели через отдельный router.

## Тип задачи

Архитектурная (модульность API).

## Задание

В файле `router.ts` необходимо:

1. Создать отдельный router:
   userRouter

2. В userRouter добавить процедуру:
   getUserById

3. appRouter должен включать:
   { user: userRouter }

4. Поведение getUserById должно соответствовать trpc16:
   - возвращать пользователя
   - выбрасывать NOT_FOUND при отсутствии

## Ограничения

- Нельзя размещать процедуры напрямую в appRouter.
- Нельзя изменять файлы в папке `_core`.
- Использовать ctx.dataAccess.
- Валидация input обязательна.

## Проверяемые требования

- Процедура доступна через appRouter.user.getUserById.
- NOT_FOUND выбрасывается корректно.
