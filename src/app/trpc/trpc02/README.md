# trpc02 — Первая query-процедура

## Цель задачи

Освоить создание первой query-процедуры в tRPC router.

## Тип задачи

Функциональная, базовая.

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter`.
2. Добавить процедуру `hello`.
3. Процедура должна быть `query`.
4. Процедура должна возвращать строку `"hello"`.

## Ограничения

- Процедура не принимает входных данных.
- Нельзя использовать глобальные состояния.
- Нельзя изменять файлы в папке `_core`.
- Нельзя добавлять другие процедуры.

## Проверяемые требования

- В router зарегистрирована процедура `hello`.
- Вызов процедуры возвращает `"hello"`.
- Процедура является query.
