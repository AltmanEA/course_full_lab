# trpc20 — Архитектурная чистота DI

## Цель задачи

Проверить, что процедура использует только injected зависимости
через context (Dependency Injection).

## Тип задачи

Архитектурная (контроль DI).

## Задание

В файле `router.ts` необходимо:

1. Создать query-процедуру `health`.
2. Процедура должна вызвать:

   ctx.dataAccess.getVersion()

3. Процедура должна вернуть:

   { status: "ok", version: string }

## Ограничения

- Нельзя импортировать data-access напрямую.
- Нельзя использовать глобальные переменные.
- Использовать только ctx.dataAccess.
- Нельзя изменять файлы в папке `_core`.

## Проверяемые требования

- getVersion вызывается через injected dataAccess.
- Возвращается корректный результат.
