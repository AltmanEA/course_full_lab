# trpc04 — Передача input в query

## Цель задачи

Освоить передачу входных данных (input) в процедуру tRPC.

## Тип задачи

Функциональная.

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter`.
2. Добавить процедуру `greet`.
3. Процедура должна быть `query`.
4. Процедура должна принимать объект:

   { name: string }

5. Процедура должна возвращать объект:

   { message: string }

   где message формируется по шаблону:
   "Hello, <name>"

## Ограничения

- input должен быть объявлен через `.input(...)`.
- Нельзя использовать глобальные переменные.
- Нельзя изменять файлы в папке `_core`.
- Нельзя добавлять другие процедуры.
- Валидация входных данных не требуется.

## Проверяемые требования

- Процедура принимает параметр `name`.
- Возвращается объект с полем `message`.
- Значение соответствует входным данным.
