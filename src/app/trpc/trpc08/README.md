# trpc08 — Middleware

## Цель задачи

Освоить создание и использование middleware в tRPC.

## Тип задачи

Архитектурно-функциональная.

## Задание

В файле `router.ts` необходимо:

1. Создать middleware, которое:
   - проверяет наличие ctx.requestId;
   - если requestId отсутствует, выбрасывает ошибку.

2. Создать процедуру `info`.
3. Процедура должна использовать созданное middleware.
4. Процедура должна возвращать:

   { requestId: string }

## Ограничения

- Ошибка должна выбрасываться через TRPCError.
- Нельзя использовать try/catch.
- Нельзя изменять файлы в папке `_core`.
- Доступ к данным должен происходить через ctx.

## Проверяемые требования

- При наличии requestId процедура возвращает его.
- При отсутствии requestId возникает ошибка.
