# trpc19 — Композиция router

## Цель задачи

Освоить объединение нескольких доменных router
в единый appRouter.

## Тип задачи

Архитектурная (композиция).

## Задание

В файле `router.ts` необходимо:

1. Использовать уже реализованные:
   - userRouter
   - postRouter

2. Объединить их в единый appRouter.

Ожидаемая структура:

{
  user: userRouter,
  post: postRouter
}

## Ограничения

- Нельзя изменять userRouter.
- Нельзя изменять postRouter.
- Нельзя добавлять новые процедуры.
- Нужно использовать router из _core.

## Проверяемые требования

- Процедуры доступны через:
  appRouter.user.*
  appRouter.post.*
