# trpc13 — Read (getUserById)

## Цель задачи

Освоить реализацию Read-операции через query с параметром id.

## Тип задачи

Функциональная (CRUD: Read).

## Задание

В файле `router.ts` необходимо:

1. Создать appRouter.
2. Добавить query-процедуру `getUserById`.
3. Процедура должна принимать input:

   { id: string }

4. Процедура должна вызвать:

   ctx.dataAccess.getUserById(id)

5. Процедура должна возвращать:

   { id: string, name: string } | null

## Ограничения

- Валидация input обязательна.
- Нельзя импортировать data-access напрямую.
- Использовать только ctx.dataAccess.
- Нельзя использовать глобальное состояние.

## Проверяемые требования

- getUserById вызывается через injected dataAccess.
- Возвращается корректный пользователь.
- Если access-слой возвращает null — процедура возвращает null.
