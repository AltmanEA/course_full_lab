# trpc06 — Mutation

## Цель задачи

Освоить создание mutation-процедуры в tRPC и понять её отличие от query.

## Тип задачи

Функциональная.

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter`.
2. Добавить процедуру `setName`.
3. Процедура должна быть mutation.
4. Процедура должна принимать input:

   { name: string }

5. Процедура должна возвращать объект:

   { status: "ok", name: string }

## Ограничения

- Процедура должна быть реализована через `.mutation(...)`.
- Валидация input обязательна.
- Нельзя использовать глобальное состояние.
- Нельзя изменять файлы в папке `_core`.
- Нельзя добавлять другие процедуры.

## Проверяемые требования

- Процедура зарегистрирована как mutation.
- Корректный input возвращает ожидаемый результат.
- Пустая строка вызывает ошибку.
