# trpc26 — Централизованная error factory

## Цель задачи

Освоить стандартизацию доменных ошибок через фабрику.

## Тип задачи

Функциональная (ошибки + API-контракт).

## Задание

Реализуйте процедуру `getItem`, которая:

- принимает input { id: string };
- если id !== '1' — выбрасывает ошибку NOT_FOUND
  через функцию createNotFoundError;
- если id === '1' — возвращает строку "item-1".

Используйте createNotFoundError из _core/errors.

## Ограничения

- Не создавать TRPCError вручную.
- Использовать createNotFoundError.
- Не использовать any.
- Не изменять _core.

## Проверяемые требования

- При id = '1' возвращается "item-1".
- При любом другом id выбрасывается ошибка с code NOT_FOUND.
