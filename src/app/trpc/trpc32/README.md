# trpc32 — useQuery с input (client-only)

## Цель задачи

Научиться передавать параметры в query-процедуру
через tRPC client.

## Тип задачи

Функциональная (client-side).

## Задание

Реализуйте функцию useUserById,
которая принимает параметр id: string
и вызывает:

trpc.user.getById.useQuery({ id })

Функция должна возвращать результат useQuery.

## Ограничения

- Использовать только trpc из client_core.
- Не добавлять дополнительную логику.
- Не использовать React-компоненты.
- Решение должно содержать 2–10 строк кода.

## Проверяемые требования

- useQuery вызывается.
- В useQuery передаётся объект { id }.
- Возвращается результат useQuery.
