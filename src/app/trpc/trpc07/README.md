# trpc07 — Использование context

## Цель задачи

Освоить использование context внутри процедуры tRPC.

## Тип задачи

Функционально-архитектурная.

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter`.
2. Добавить query-процедуру `info`.
3. Процедура не принимает input.
4. Процедура должна возвращать объект:

   { requestId: string }

5. Значение requestId должно браться из context.

## Ограничения

- Нельзя использовать глобальные переменные.
- Нельзя передавать requestId напрямую в процедуру.
- Доступ к данным должен происходить только через `ctx`.
- Нельзя изменять файлы в папке `_core`.

## Проверяемые требования

- Процедура возвращает requestId из context.
- Разные context дают разные результаты.
