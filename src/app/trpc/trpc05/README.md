# trpc05 — Валидация input

## Цель задачи

Освоить декларативную валидацию входных данных в tRPC-процедуре.

## Тип задачи

Функциональная (валидация + обработка ошибки).

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter`.
2. Добавить процедуру `greet`.
3. Процедура должна принимать input:

   { name: string }

4. Поле `name` не должно быть пустой строкой.
5. Процедура должна возвращать:

   { message: "Hello, <name>" }

## Ограничения

- Валидация должна быть декларативной.
- Нельзя использовать ручную проверку через if.
- Нельзя использовать try/catch.
- Нельзя изменять файлы в папке `_core`.
- Нельзя добавлять другие процедуры.

## Проверяемые требования

- Корректный input возвращает результат.
- Пустая строка вызывает ошибку.
- Ошибка возникает до выполнения логики процедуры.
