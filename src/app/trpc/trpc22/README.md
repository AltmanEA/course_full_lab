# trpc22 — Timing middleware

## Цель задачи

Освоить middleware как инструмент инфраструктурной логики.
Научиться измерять время выполнения процедуры.

## Тип задачи

Функциональная (middleware).

## Задание

Реализуйте middleware `timingMiddleware`, который:

- измеряет время выполнения процедуры;
- после выполнения вызывает `ctx.logger?.info`;
- передаёт в logger строку в формате:
  "Procedure executed in Xms".

Middleware должен применяться к процедуре `ping`.

Процедура `ping` должна возвращать строку `"pong"`.

## Ограничения

- Использовать t.middleware.
- Не изменять _core.
- Не использовать any.
- Не использовать глобальные значения.
- Если logger отсутствует — middleware не должен выбрасывать ошибку.

## Проверяемые требования

- Процедура возвращает "pong".
- logger.info вызывается один раз.
- logger.info получает строку, содержащую "ms".
- Middleware корректно вызывает next().
