# trpc24 — Middleware, модифицирующий результат

## Цель задачи

Освоить middleware, который изменяет возвращаемый результат процедуры.

## Тип задачи

Функциональная (response shaping).

## Задание

Реализуйте middleware `wrapResultMiddleware`, который:

- выполняет процедуру через next();
- возвращает модифицированный результат;
- новый результат должен иметь вид:

{
  data: <оригинальный результат>,
  requestId: ctx.requestId
}

Middleware должен применяться к процедуре `getMessage`.

Процедура `getMessage` должна возвращать строку `"hello"`.

## Ограничения

- Использовать t.middleware.
- Не изменять _core.
- Не использовать any.
- Если requestId отсутствует — вернуть его как undefined.
- Не ломать цепочку middleware (вернуть корректный объект результата).

## Проверяемые требования

- Результат процедуры имеет форму:
  { data: 'hello', requestId: 'req-1' }
- При отсутствии requestId он равен undefined.
