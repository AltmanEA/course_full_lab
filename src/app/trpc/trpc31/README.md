# trpc31 — Первый useQuery hook

## Цель задачи

Научиться вызывать типизированную query-процедуру
через tRPC client на стороне UI.

## Тип задачи

Функциональная (client-side).

## Задание

Реализуйте функцию useUsers,
которая вызывает процедуру:

trpc.user.getAll.useQuery()

Функция должна возвращать результат вызова useQuery.

## Ограничения

- Использовать только trpc из client_core.
- Не добавлять дополнительную логику.
- Не использовать React-компоненты.
- Решение должно содержать 2–10 строк кода.

## Проверяемые требования

- useQuery вызывается.
- Возвращается результат вызова useQuery.
