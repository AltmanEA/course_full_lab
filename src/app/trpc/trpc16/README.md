# trpc16 — NOT_FOUND вместо null

## Цель задачи

Освоить выброс доменной ошибки вместо возврата null при отсутствии сущности.

## Тип задачи

Функционально-архитектурная (обработка ошибок).

## Задание

В файле `router.ts` необходимо:

1. Создать query-процедуру `getUserById`.
2. Процедура должна принимать input:

   { id: string }

3. Процедура должна вызвать:

   ctx.dataAccess.getUserById(id)

4. Если пользователь найден — вернуть его.
5. Если пользователь не найден — выбросить:

   TRPCError({ code: "NOT_FOUND" })

## Ограничения

- Нельзя возвращать null.
- Ошибка должна выбрасываться через TRPCError.
- Нельзя использовать try/catch.
- Использовать только ctx.dataAccess.
- Валидация input обязательна.

## Проверяемые требования

- Возвращается пользователь при наличии.
- При отсутствии выбрасывается NOT_FOUND.
