# trpc03 — Возврат объекта из query

## Цель задачи

Понять, что tRPC типизирует не только примитивы, но и структуру возвращаемых данных.

## Тип задачи

Функциональная.

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter`.
2. Добавить процедуру `hello`.
3. Процедура должна быть `query`.
4. Процедура должна возвращать объект:

   { message: "hello" }

## Ограничения

- Нельзя возвращать строку напрямую.
- Структура объекта должна быть фиксированной.
- Нельзя изменять файлы в папке `_core`.
- Нельзя добавлять другие процедуры.

## Проверяемые требования

- Процедура `hello` возвращает объект.
- Объект содержит поле `message`.
- Значение поля равно `"hello"`.
