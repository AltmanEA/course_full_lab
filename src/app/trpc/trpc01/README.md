# trpc01 — Минимальный router

## Цель задачи

Освоить создание минимального tRPC router и экспорт типа AppRouter.

## Тип задачи

Архитектурная, базовая.

## Задание

В файле `router.ts` необходимо:

1. Создать `appRouter` с использованием `router` из `_core/trpc`.
2. Router должен быть пустым (без процедур).
3. Экспортировать тип `AppRouter`, выведенный из `appRouter`.

## Ограничения

- Нельзя добавлять процедуры.
- Нельзя использовать глобальные состояния.
- Нельзя изменять файлы в папке `_core`.
- Тип `AppRouter` должен выводиться через `typeof`.

## Проверяемые требования

- `appRouter` является корректным tRPC router.
- Router не содержит процедур.
- Тип `AppRouter` корректно экспортирован.
