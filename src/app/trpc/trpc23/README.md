# trpc23 — Audit middleware

## Цель задачи

Освоить post-execution middleware.
Научиться использовать injected зависимость (auditService)
для записи результата выполнения процедуры.

## Тип задачи

Функциональная (middleware + DI).

## Задание

Реализуйте middleware `auditMiddleware`, который:

- выполняет процедуру через next();
- после выполнения вызывает ctx.auditService?.record;
- передаёт в record объект:
  {
    path: <имя процедуры>,
    result: <результат выполнения>
  }

Middleware должен применяться к процедуре `hello`.

Процедура `hello` должна возвращать строку `"world"`.

## Ограничения

- Использовать t.middleware.
- Не изменять _core.
- Не использовать any.
- Не использовать глобальные значения.
- Если auditService отсутствует — middleware не должен выбрасывать ошибку.

## Проверяемые требования

- Процедура возвращает "world".
- auditService.record вызывается один раз.
- В record передаётся корректный объект.
- Middleware не ломает выполнение процедуры.
