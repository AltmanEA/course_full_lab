# trpc30 — Shared context mutation

## Цель задачи

Освоить расширение контекста внутри middleware
и использование расширенного ctx в процедуре.

## Тип задачи

Функциональная (middleware + ctx mutation).

## Задание

Реализуйте middleware `requestIdMiddleware`, который:

- добавляет в ctx новое поле:
  requestId: 'req-123';
- передаёт расширенный ctx дальше через next({ ctx: ... }).

Процедура `getInfo` должна:

- возвращать строку:
  "request:req-123".

## Ограничения

- Не изменять _core.
- Не использовать any.
- Использовать next({ ctx: ... }) для расширения контекста.
- Не мутировать исходный ctx напрямую.

## Проверяемые требования

- Результат процедуры равен "request:req-123".
- Расширенный ctx доступен внутри процедуры.
