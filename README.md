# Задачи по NextJs

[Теоретический курс](https://altmanea.ru/course_full/)

### Инструкция

#### Как запускать задачи 

- Клонируйте проект.
- Установите пакеты ```npm install```.
- Установите расширение для VS Code [Examenator](https://marketplace.visualstudio.com/items?itemName=AltmanEA.examenator). 

При нажатии в расширении на блок задач откроется список задач этого блока.
При нажатии на тест - откроется список задач этого теста (выбирается случайным образом).
В при нажатии на задачу в списке открываются редакторы с условиями задачи, исходными кодами и тестами, а также запускается тест в терминале. 


####  Проверка выполнения лабораторных работ (заочный вариант)

В этом варианте нужно создать форк репозитория под аккаунтом github, в котором прописаны имя и фамилия студента. Решение каждой задачи оформляется в виде отдельного коммита, в сообщении которого указан номер задачи. При возникновении сомнений в самостоятельности выполнения задачи обучающимся проверка решения задач будет проводиться в очном варианте (возможно по видеосвязи).
